# 🚀 楽天ドリルダウン・リサーチツール

楽天APIを活用して、特定のカテゴリを深掘り（ドリルダウン）しながらランキングデータを一括取得するツールです。

## ✨ 特徴
- **テンキー特化操作**: `00`で確定、`000`で戻るなど、半角全角を切り替えずに爆速リサーチ。
- **階層別CSV出力**: カテゴリ構造を維持したまま、メーカー・ショップ名付きで保存。
- **AI連携前提**: クレンジングをAIに任せるための「生データ」取得に特化。

## 🛠 使い方
1. 楽天Developersで `APP_ID` を発行。
2. Google Colabで実行し、カテゴリ番号を選択して潜る。
3. `00` で件数を指定してデータをぶっこ抜く。
